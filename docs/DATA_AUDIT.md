# Public wearable dataset audit

Checked October 17, 2026 against the dataset owners' repository pages.

## PhysioNet Wearable Device Dataset

[Wearable Device Dataset from Induced Stress and Structured Exercise Sessions, version 1.0.1](https://physionet.org/content/wearable-device-dataset/1.0.1/) is the closest match to the first exertion-and-recovery pilot. It contains Empatica E4 PPG, accelerometry, skin temperature, EDA, and heart-rate values derived from BVP; the protocol includes aerobic and anaerobic cycling, cooldown, and rest. The repository page describes 36 stress, 30 aerobic, and 31 anaerobic participant records, and lists known incomplete, duplicated, and split sessions. Check `data_constraints.txt` before selecting recordings. Its downloaded files are open to anyone under the listed Open Data Commons Attribution License v1.0, with attribution required.

The repository page describes each `HR.csv` as a start-time header, a sampling-rate header, then one value per sample. HR is **derived from the wrist BVP**, not an ECG reference. That is adequate for a narrow same-stream trajectory/predictor smoke test, but it does not provide an independent reference target for validating wearable accuracy or physiological recovery claims. The protocol's activity transitions and final cooldown/rest make the data useful for exercising time-series splitting and forecast code; those labels must be reconstructed from the protocol and event marks, not invented from the HR curve.

One actual source recording is included at [`sources/physionet-wearable/S06_AEROBIC_HR.csv`](../sources/physionet-wearable/S06_AEROBIC_HR.csv). It is the original 14,502-byte `AEROBIC/S06/HR.csv` downloaded from [the versioned PhysioNet file](https://physionet.org/files/wearable-device-dataset/1.0.1/Wearable_Dataset/AEROBIC/S06/HR.csv). Its first two lines identify start time `2013-02-25 18:38:55` and 1 Hz sampling. The file contains 2,057 HR samples spanning 2,056 seconds (34 minutes 16 seconds); values range from 59.17 to 127.48 bpm. SHA-256: `a4de7462237154dc43718399faffd738178fc1ab21b64496d774f1f7cd326135`. Dataset citation: Hongn et al. (2025), [doi:10.13026/he0v-tf17](https://doi.org/10.13026/he0v-tf17); the dataset page also asks users to cite its original [Scientific Data paper](https://doi.org/10.1038/s41597-025-04845-9). The individual recording is retained unchanged; it has not been labeled into benchmark roles or presented as an episode.

## UCI PPG-DaLiA

[PPG-DaLiA at UCI](https://archive.ics.uci.edu/dataset/495/ppg%20dalia) has 15 participants and synchronized wrist PPG and motion plus chest-worn ECG; its ECG is described as the heart-rate ground truth. It is a stronger independent reference for PPG heart-rate estimation than the PhysioNet HR derivative. Its published download is 2.7 GB, and the repository describes its focus as motion-compensated heart-rate estimation during daily-life activities. It does not directly provide the structured exercise-and-recovery episodes that the first benchmark needs. The dataset has a CC BY 4.0 license and requires attribution. We did not download the 2.7 GB archive.

## Adapter contract and current gap

`benchmark.data.load_csv` accepts a caller-supplied canonical CSV with exactly `participant_id,session_id,time_s,hr_bpm,role`. It does not fetch or convert source datasets: conversion must preserve session-relative time and the caller must state target provenance explicitly (for example, `Empatica BVP-derived HR`, or `ECG-derived reference HR`). It reports participant/session/row counts and per-session time coverage, and rejects reused session IDs, role conflicts, duplicate timestamps, missing identifiers, and invalid values. The contract treats one `session_id` as one complete source recording; it does not cut windows or derive benchmark roles. Distinct complete sessions may reuse relative timestamps because their clocks start at zero. `make_episode` selects one participant's supplied recordings and calls the workspace episode validator; it requires support, development, and test roles but never invents them. The caller must prepare the recording-level split and must not disguise overlapping windows from one source recording as distinct sessions.

The included PhysioNet sample demonstrates actual, provenance-preserving input availability. It is **not** yet a calibrated benchmark: no canonical conversion, event-aligned session windows, multi-participant coverage audit, frozen participant/session split, or independent reference target has been produced. UCI could supply a reference stream, but requires a documented conversion pipeline and significant download/processing. Before a scored benchmark is frozen, prepare non-overlapping windows with source-recording identity tracked outside this five-column transport CSV, choose development/test recordings at the participant or source-session level, preserve dataset event metadata, and compare against baselines on untouched recordings.
